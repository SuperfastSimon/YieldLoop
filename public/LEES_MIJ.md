# YieldLoop — overdrachtspakket (2026-08-29)

Gebruik dit in een **nieuw Grok-gesprek**.

## Stappen

1. Open een nieuw gesprek (Grok Build als je de app weer wilt laten draaien).
2. Plak de inhoud van `attachments/YIELDLOOP_NIEUW_GESPREK.md` als eerste bericht.
3. Upload deze zip (of de map `product/` + `brand/` + `docs/`).
4. Zeg wat je wilt: verder bouwen, restylen, echte adapters, publisher, CLI, enz.

## Wat zit erin

| Map | Inhoud |
| --- | --- |
| `attachments/` | Plakklare Grok-prompt + oorspronkelijke bouwbrief |
| `docs/` | Handover, safety (INV file:line), compliance, review, brief-correcties |
| `product/` | Werkende TypeScript-kernel, routes, UI, golden set, styles, site.json |
| `brand/` | favicon.svg, og.jpg (1200×630), x-banner.jpg (1200×264) |

Geen `node_modules`, geen sandbox-harness. De kernel is zelfstandig leesbaar.

## Demo (10 min) als de app weer draait

1. Commando → **Demo-cyclus** (memo + concept-artefact, geen stille publish).
2. Content → golden-artefact zonder disclosure is **Geblokkeerd**, nooit Live.
3. Station → **Kloon station** zonder token = voorstel. Keuren op Commando.
4. Compliance → **Golden set**: vier negatieven rood, test groen.
5. Sidebar-kill-switch haalt publishers offline.
